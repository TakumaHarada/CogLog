# プロダクトとドメイン

## プロダクト

CogLog は、エアロバイクの運動履歴を記録し、減量を支える Flutter アプリケーションである。

- 記録の対象は、据え置き型のエアロバイクで行った運動である。
- 主機能は、運動履歴の記録である。
- 利用者が支える目的は減量である。
- 画面の文言は日本語を優先し、英語も持つ。
- 対応するのは Android と iOS である。
- ヘルスコネクトおよび Apple ヘルスケアと連携する。

## 運動履歴

1 件の運動履歴は、1 回の乗車であり、メーターパネル写真 1 枚である。

- まだ運動履歴になっていない撮影は、新しい運動履歴になる。
- 運動履歴になった写真を撮り直すときは、前の写真を上書きする。別の運動履歴は作らない。上書きしたときは、走行距離、運動時間、平均速度、消費カロリーを読み直す。

1 件は記録日時を持つ。記録日時の決め方は次の順である。

1. メーターパネル写真の撮影日時を使う。
2. 撮影日時が取れないときは、運動履歴の作成開始日時を使う。
3. 利用者は記録日時を手で変更できる。

写真の上書きで記録日時を新しい撮影日時へ変えるかは未確定。

1 件は次の 4 つを必ず持つ。保存するのはこの 1 組であり、手打ちする前の読み取り値は持たない。

| 属性 | 単位 |
| --- | --- |
| 走行距離 | km |
| 運動時間 | 時、分、秒 |
| 平均速度 | km/h |
| 消費カロリー | kcal |

運動時間の時、分、秒がすべて 0 の運動履歴は保存できない。

いま定義する単位系はこの 1 つである。あとから別の単位系を追加できる余地を残す。追加する単位系の中身は、この文書に書いてから実装する。

値の入り方は 2 通りある。

- メーターパネルを撮影し、読み取りエンジンで解析する。
- 手打ちする。読み取りエンジンが使えないときと、読み取りミスを調整するときに使う。

平均速度は、メーターパネルに表示があるときはその値を使う。表示が無いときは、走行距離と運動時間から次の式で求める。

```text
平均速度 (km/h) = 走行距離 (km) / 運動時間 (時)
```

運動時間は時、分、秒を時に直してから割る。パネルの値と計算結果がずれるときは、パネルの値を使う。

運動履歴は編集できる。削除もできる。

どの端末でどの読み取りエンジンを使うかは未確定。

## 期間集計

期間の境界は、端末の現地時刻で切る。記録日時を端末の現地時刻へ直した日時で、運動履歴を期間へ振り分ける。

| 期間 | 境界 |
| --- | --- |
| 本日 | 現地日付の 0:00 から、翌日 0:00 の直前まで |
| 今週 | 月曜 0:00 から、次の月曜 0:00 の直前まで |
| 今月 | その月の 1 日 0:00 から、翌月 1 日 0:00 の直前まで |

期間集計が合計するのは次の 3 つである。

- 走行距離
- 消費カロリー
- 運動時間

集計期間は利用者が選ぶ。トップ画面が最初から示す切り口は、本日、今週、今月の 3 つである。利用者が選ぶ期間も、同じ現地時刻で切る。

運動履歴を編集または削除したあとは、期間集計をやり直す。

## ヘルスサービス

1 件の運動履歴は、ヘルスサービス上の運動 1 件に対応する。

CogLog からヘルスサービスへ書くのは、運動履歴の次の 3 つである。

- 走行距離
- 運動時間
- 消費カロリー

運動履歴を編集したときは、対応する運動を更新する。削除したときは、対応する運動を削除する。ヘルスサービスが更新または削除を受け付けないときの扱いは未確定。

体重、骨格筋率、体脂肪率はヘルスサービスから読む。これらの入力元はヘルスサービスである。

| 指標 | 単位 |
| --- | --- |
| 体重 | kg |
| 骨格筋率 | % |
| 体脂肪率 | % |

身体の指標の単位系も、あとから追加できる余地を残す。追加する単位系の中身は、この文書に書いてから実装する。

同じ現地日付に指標が複数あるときは、計測日時が最も遅い値をその日の値にする。

## 比較

比較では、利用者が選んだ期間について、次の推移を日ごとの点でグラフに示す。点の日付は、端末の現地日付である。

| 指標 | 1 日の点 |
| --- | --- |
| 運動時間 | その日の運動履歴の合計 |
| 走行距離 | その日の運動履歴の合計 |
| 消費カロリー | その日の運動履歴の合計 |
| 体重 | その日の最終の計測値 |
| 体脂肪率 | その日の最終の計測値 |
| 骨格筋率 | その日の最終の計測値 |

運動が無い日、または身体の指標が無い日に点を置くかは未確定。
